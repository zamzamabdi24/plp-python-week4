# Week 4 Assignment: Hands-On Lab - Grades, Eligibility & Smart Decisions

## Files

- `welcome.py` – defines a `welcome(name)` function and prints greetings for three names.
- `toolbox.py` – defines `double(number)`, `is_pass(score)`, and `greet(name, greeting="Hello")`, then tests them.

## Reflection

The hardest function to write was `greet` because I had to remember how default parameters work and how to format the string with both the greeting and the name. Once I used an f-string, it became much clearer.
